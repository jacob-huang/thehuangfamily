# Images

Drop your family photos in this folder and reference them from the HTML, e.g.:

```html
<img src="/images/beach-2026.jpg" alt="Family at the beach, 2026" style="width:100%; border-radius:14px;" />
```

To replace the placeholder tiles on the homepage, edit the `.photo` blocks in `index.html`
and swap them for `<img>` tags pointing at files here.
